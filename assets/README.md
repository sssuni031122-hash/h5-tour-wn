## 建议格式

- RGB 色彩模式。
- JPG/WebP 用于无透明背景图，PNG 用于需透明的素材。
- 建议设计基准宽度 750px。
- 首屏图片尽量不超过 2MB，单张景点图建议不超过 500KB。

如果设计师交付的扩展名不是 `.jpg`，请在 `config.js` 中只修改对应的素材路径。
